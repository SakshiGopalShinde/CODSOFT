# Codsoft Android App Development Projects

This repository contains Android applications developed as part of an Android App Development internship. The goal of these projects was to strengthen core Android development skills, understand mobile UI/UX design, and build fully functional applications using standard Android development practices.

---

## Repository Overview

The repository includes two independent Android applications, each located in its own folder.

```
Codsoft-Android-Projects/
│
├── GetItDone/      # To-Do List Application
└── Alarms/         # Alarm Clock Application
```

---

## Projects

### 1. GetItDone – To-Do List Application

A simple and efficient task management app that helps users organize daily activities and improve productivity.

**Key Features**

* Add, edit, and delete tasks
* Mark tasks as completed
* Clean and user-friendly interface
* Lightweight and fast performance
* Local storage for saving tasks

**Learning Focus**

* Android UI layouts
* RecyclerView usage
* Data persistence concepts
* Event handling in Android

---

### 2. Alarms – Alarm Clock Application

A standard alarm clock application that allows users to set and manage alarms for daily schedules.

**Key Features**

* Set multiple alarms
* Edit or delete alarms
* Alarm notifications and sound alerts
* Simple and intuitive UI

**Learning Focus**

* Working with time and date in Android
* Background services and notifications
* AlarmManager usage
* App lifecycle handling

---

## Tech Stack

* Java / Kotlin (Android Development)
* Android Studio
* XML for UI Design
* Android SDK Components

## How to Run the Projects

1. Clone the repository

```
git clone https://github.com/your-username/repository-name.git
```

2. Open the project folder in **Android Studio**
3. Let Gradle sync complete
4. Run the app on an emulator or Android device
